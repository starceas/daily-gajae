카카오 연결 계약

작성 시각 / 출처 확인일 / 과제:

항목 현재 답 근거와 미확인
요구 경로 로그인 / 나에게 보내기 / 친구 메시지 / 채널 챗봇 / 그 밖 경로
대회가 이 경로를 허용하고 요구하는가
사용할 기존 계정·채널·앱·권한 비밀값을 적지 않는다.
내 서버가 받아야 하는 요청 ID·사용자 입력·세션·필수 필드
돌아가야 하는 응답 형식과 응답 기한
외부 서버 주소·HTTPS·접근 가능 여부 로컬 주소만으로 외부 접근을 입증하지 않는다.
중복·시간 초과·응답 상실 때 정책 재시도해도 되는 동작과 보내지 않을 동작
쓰기/송신 전 사람 결정이 필요한 행동
계정·키·권한·비용 막힘 시 대안 로컬 요청 fixture → 어댑터 → 응답 대조
제출 형식·허용 도구·규정 미공개면 미확인

증거는 네 칸으로 나눈다

층 시험 결과와 증거
로컬 어댑터 가상 카카오 요청 → 형식에 맞는 응답
실제 모델 승인된 기존 경로로 입력 → 도구 → 근거 있는 답
카카오 네이티브 공식 테스트 경로에서 실제 요청 → 서버 → 실제 표시
대회 요건 공개된 허용 경로·제출 형식과 결과물을 대조

로컬 합격은 네이티브 합격이 아니다. 메시지 전송 API 성공은 챗봇 양방향 대화 성공이 아니다. 연결과 제출을 못 했더라도 사고 실습은 계속할 수 있다.
