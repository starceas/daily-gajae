# 모의 제출 묶음과 최종 대조

이 양식은 모의 제출용이다. 공식 제출 형식이 공개되면 그 형식이 우선한다.

| 파일/증거 | 넣을 내용 | 대조 결과 |
|---|---|---|
| 인터뷰 기록 | 질문·답·추정·확인 | |
| 요구 계약 | 성공조건, 입력/출력, 금지, 미확인 | |
| 실행 안내 | 다른 세션에서 따라 할 명령과 준비물 | |
| 구현/설정 사본 | 비밀값 없는 최소 결과물 | |
| 시험표와 출력 | N·P·B, 실패/수정, 확인용 노출 여부 | |
| 연결 계약 | 모의/실제 모델/카카오/제출 요건별 증거 | |
| 제한사항 | 미지원·미실행·규정 미확인 | |

## 공개 규정 확인 후 채울 것

- 공식 공지 URL와 확인일:
- 제한시간과 시작/종료 방식:
- 허용 모델·도구·기존 코드·외부 도움:
- 필수 카카오 경로와 준비 가능한 계정/권한:
- 제출 파일/URL/동영상/접근 권한:
- 개인정보·비밀값 포함 여부:

공식 형식이 미확인이면 “모의 제출 묶음 완성, 실제 제출 요건 미확인”이라고 적는다. 이 자료 작성 과정에서는 제출·공개·실제 송신을 하지 않는다.
