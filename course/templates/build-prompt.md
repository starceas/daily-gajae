# 한 세션 구현 발주

아래 칸을 채워 기존 승인된 대화형 AI CLI 한 세션에 준다. 다른 워커·모델 호출은 요구하지 않는다. 구현 전에 입력/출력 예를 네가 확정한다.

```text
나는 코딩 문법 대신 요구·시험·진단을 배우고 있다.
작업 폴더: [새 practice 하위 폴더의 절대 경로]
의도: [누구의 어떤 일을 돕는지 한 문장]
읽을 자료: [가상 자료 경로]
입력 예: [실제 예]
기대 출력: [실제 예, 근거 ID, 미확인 포함]
필수 시험: [실행 전에 고정한 N개]
허용 도구: [로컬 읽기/쓰기/실행 범위]
실패 응답: [자료 없음·충돌·실행 실패별]
금지 행동: 외부 송신·공개·새 계정·키·결제·기존 설정 변경.
rm -rf, git reset --hard, git clean -fdx, force push, main merge,
비밀값 노출, 숨은 외부 모델 호출을 하지 마라.

위 요구를 만족하는 최소 결과물 하나를 만들어라.
표준 라이브러리/기존 도구로 가능하면 추가 설치하지 마라.
명령·입력 파일·출력 파일·필수 시험을 먼저 보여줘라.
코드 문법 설명 대신 내가 조작할 입력과 확인할 결과를 설명해라.
모의 구현인지 실제 모델을 호출하는지 명시해라.
내가 실행할 명령과 각 명령의 기대 결과를 남겨라.
완료 주장은 실행 증거로 뒷받침하고 미실행은 미실행으로 표시해라.
```

실패 후에는 다음을 덧붙인다.

```text
실패 입력: [...]
기대 출력: [...]
실제 출력: [...]
내 원인 후보: [...]
이 후보와 다른 원인을 구별하는 최소 시험 하나를 제안해라.
시험 N·기대값을 바꾸거나, 다른 기능까지 수정하지 마라.
수정 후 같은 입력을 다시 실행하고 전후 결과를 남겨라.
```
