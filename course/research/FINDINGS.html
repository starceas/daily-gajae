대회·카카오 조사 판정과 인계

확인일: 2026-10-01 KST. 공개 문서 조사 결과이며 실제 연결·제출 검증은 미실행이다. 최종 독립 검토 전이다.

교재는 공식 FAQ에서 새로 확인한 항목을 반영하고, 대회가 요구하는 기술 연결 방식은 미확인으로 유지해야 한다. 기본 실습은 오프라인으로 닫을 수 있다. 카카오 연결은 아래 조건을 구분하는 별도 단계다.

공식 일반 안내와 아직 읽지 못한 상세 규정은 구별한다. 도구 제한 없음이 타인의 도움·계정 공유·모든 외부 송신까지 허용한다는 뜻은 아니다. 참가 등록 여부와 개인 수신 메일은 조사하지 않았다.

2. 카카오의 다섯 경로

이 표는 기능 선택을 위한 조사다. 설정·신청·실행 지시가 아니며, 이번 계약에서 실제 송신은 전부 미실행이다.

경로 되는 일 실제 연결에 필요한 조건 대회 적용 판정·오프라인 대안
카카오 로그인 사용자를 인증하고 동의 범위에 따른 접근 토큰을 얻는 과정 개발자 앱, 로그인 설정, 해당 방식의 리다이렉트 등 대회 참가 로그인과 참가자 앱 개발은 다르다. 로그인 성공→대화 수신 성공으로 판정하지 않는다. 대안: 가상 인증 상태표. K01
나에게 보내기 로그인한 본인의 나와의 채팅으로 메시지 발송 앱·카카오 로그인·사용자 액세스 토큰·talk_message 동의·템플릿/링크 설정 다른 심사자에게 보내기나 채팅 수신 기능을 입증하지 않는다. 대안: 본인 대상 가상 발송함. K03
친구 메시지 사용자가 같은 서비스의 친구를 골라 발송 양측 친구 관계·앱 연결·동의, 수신자 식별자. 심사 전 양측 앱 멤버, 일반 서비스에는 추가 권한 심사 임의 사용자에게 자동 안내하는 범용 봇 경로가 아니다. 대안: 관계·동의 조합 시험표. K04
채널 챗봇 채널 사용자 발화를 블록/스킬로 처리하고 응답 봇·채널 및 연결 권한, 배포. 외부 처리는 카카오가 접근 가능한 스킬 서버 대회에서 요구하는지 미확인. 대안: 가상 발화 JSON→응답 JSON, 지연·재시도 모형. K05, K06
비공식 개인계정 자동화 개인 메신저 화면/알림/비공개 통신을 조작하는 별도 방식 공식 네 경로와 다른 기술·운영 조건 검토한 공식 문서에서 지원 경로로 확인되지 않았다. 허용·안정성·대회 인정도 미확인. 이 계약의 설정 변경·송신 금지 때문에 채택하지 않는다. 대안: 가상 대화 기록.

추가 구별: 카카오톡 공유는 사용자가 카카오톡에서 수신 대상을 고르는 기능이고 REST API를 지원하지 않는다. 친구 메시지와 알림톡/채널 발송도 목적·발신 주체가 다르다. 친구 메시지 튜토리얼은 서비스의 일방적 자동 발송 용도로 사용할 수 없다고 안내한다. K02, K04

3. 실제 요건·시간 제약과 상충

항목 확인 내용 교재에 넣을 결론
친구 메시지 제공량 심사 전 앱 기준 일 30건, 한 번에 최대 5명. 승인 뒤에도 쿼터가 있다. K04, K02 반복 시험을 실발송에 의존하지 않는다. 본인 메시지의 개별 제한 표기를 전체 API 무제한으로 일반화하지 않는다.
친구 메시지 권한 비즈 앱 전환·신청 자격·필요시 비즈니스 정보 심사·추가 기능 신청 단계가 있다. K04 당일 승인·몇 분 완성을 약속하지 않는다. 현재 계정 보유 조건과 심사 소요기간은 미확인.
채널 연결 권한 봇 마스터가 채널 매니저 이상 권한을 가져야 한다. 채널에 앱이 연결돼 있으면 앱 EDITOR 이상도 필요. 기존 봇·채팅방 메뉴와 충돌 가능. K05 연결 가능을 기본값으로 두지 않는다. 기존 채널 설정을 바꾸는 실습은 넣지 않는다.
외부 스킬 접근 공인 IP 또는 공중망 도메인이 필요하다. K06 로컬 실행은 스킬 서버 접근성 증거가 아니다. 터널·외부 배포는 이번 범위 밖이다.
일반 스킬 응답 고정 타임아웃 안내는 5초. K06 모델 시간 외에 대기·통신·응답 조립까지 고려한다.
콜백 방식 블록 콜백 설정, 최초 응답의 useCallback: true, 일회성 URL로 후속 응답. K07 일반 응답과 늦게 전달하는 응답을 별도 상태로 다룬다.
콜백 유효시간 같은 문서 개요는 5분, 오류 표는 1분 이내 요청으로 안내한다. K07 미확인(문서 내부 상충). 1분·5분 중 하나를 실제 보장값으로 채택하지 않는다.
콜백 시험·승인 봇테스트에서는 완전 지원되지 않으며 배포 후 채널 시험을 안내한다. 현재 문서에서 승인 필수 여부·처리기간의 확정 근거는 찾지 못했다. K07 봇테스트 통과로 실제 수신을 증명하지 않는다. 과거의 ‘승인 1~2영업일’을 현재 사실로 옮기지 않는다.

가격·호스팅 비용과 계정별 유료 설정은 조사·변경하지 않았다. 모든 경로를 무료라고 표시할 근거가 없다. 새 키·계정·결제·설정·공개·송신이 필요한 지점은 계약 밖으로 표시하고 오프라인 과제를 제공한다.

4. 미확인을 남기면서 실행 범위를 닫는 규칙

다음은 조사에 근거한 설계 제안이며 대회 규정이 아니다.

연결 진행 조건을 다음과 같이 정의한다.

G = R ∧ A ∧ Q ∧ E

  • R: 공식 과제에서 요구하는 연결 방식·제출 형식이 확인됐다.
  • A: 그 구체적 행위가 사용자에게 승인됐다.
  • Q: 필요한 계정·권한·비용·제공량 조건이 확인됐다.
  • E: 해당 방식의 실제 시험 환경과 성공 증거 수집 방법이 마련됐다.

각 값은 확인 / 부정 / 미확인 중 하나다. 네 값이 모두 확인일 때만 실제 연결 단계로 진행한다. 하나라도 부정 또는 미확인이면 오프라인 모의 단계로 종료한다. 이번 조사에서는 실제 연결 방식 R이 미확인이고 송신·설정 행위는 허용되지 않으므로 실제 연결은 진행하지 않는다.

이후 밝혀질 대회 요구 그때 선택할 경로 지금 만들 수 있는 것
참가 계정 연동만 요구 주최측 참가 절차를 확인 참가 준비 확인표와 기술 구현 요구의 분리
주최측 연결 도구 제공 그 도구의 실제 입력·출력·권한 계약부터 확인 교체 가능한 입력/응답 경계
참가자 엔드포인트/채널 구축 요구 정확한 요구와 사용자 승인 확보 후 별도 연결 작업 가상 요청·응답과 오류·시간초과 시험
상세 규정이 계속 미확인 제출 가능·대회 준비 완료로 판정하지 않음 인터뷰→요구 계약→시험→모의 제출 묶음

증거는 D=문서, O=오프라인, M=실제 모델, K=실제 카카오, J=대회 수용으로 각각 기록한다. O=통과에서 M/K/J=통과를 추론할 수 없다. 이 조사에서 확인한 것은 D뿐이다.

시간 과제의 예: T = 통신 + 대기 + 모델 처리 + 응답 조립. 오프라인 학습 예산을 4초로 정하고 3.9초/4.1초 사례를 나누는 것은 가능하다. 4초는 학습 설정, 5초는 K06의 공식 문서 값이며 실제 네트워크 성능은 미측정이다. 콜백 유효시간 상충은 이런 임의 예산으로 해결되지 않는다.

5. 작성자·독립 검토자에게 넘길 확인점

  1. 시간과 도구 허용을 통째로 ‘미공개’라고 남긴 초안 문구를 C01의 현재 공개 내용으로 고친다. 제출 형식·구체적 연결은 계속 미확인으로 남긴다.
  2. 첫 90분·모의전 3회의 제한시간과 채점표에 ‘학습 설정’을 표시한다. 공식 제한시간과 연습 시간표의 출처를 섞지 않는다.
  3. 각 시험은 실행 전 분모를 고정한다. 수정용과 확인용을 분리하고, 통과한 사례만 분모에 넣지 않는다.
  4. 카카오 모의 어댑터 결과를 실제 연결로 보고하지 않는다. 외부 계정·메시지·네트워크 접근 없이 수행할 대체 경로를 둔다.
  5. 최종 독립 검토에서 출처·본문·시험 산출물을 대조한다. 이 연구 세션의 설계 처분 확인은 완성 교재의 최종 PASS를 대신하지 않는다.
