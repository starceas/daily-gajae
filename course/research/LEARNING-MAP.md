## 2. 고정 분모로 닫는 학습 평가

교재 작성자가 실행 전에 버전과 시험 ID를 고정한다. 한 시험의 통과는 그 시험에 적힌 **모든 필수 조건**이 관측됐을 때만 인정한다.

`N = 사전 고정 필수 시험 수 > 0`

`P = 통과 시험 수`, `F = 실패 시험 수`, `U = 미실행·판정 불가 시험 수`

`N = P + F + U`, `관측 통과율 = P / N`

`과제 통과 = (P = N) ∧ (B = 0) ∧ (미확인 항목을 명시함)`

`B`는 핵심 경계 위반 횟수다. 외부 송신, 금지된 모델 호출, 근거 없는 실제 연결 성공 표기 등을 포함한다. `N=0`이면 판정 불가이고, 미실행 항목을 빼서 분모를 줄일 수 없다. 이 식은 해당 시험판의 관측 결과만 판정한다. 임의의 미래 입력에도 성공한다는 확률 보증이 아니다.

작성자가 준비할 최소 사례군은 다음과 같다. 아래는 대회 숨은 채점 기준이 아니라 **교육용 예시**다.

| 사례군 | 기대 행동 | 확인할 증거 |
| --- | --- | --- |
| 정상 요구 | 필요한 자료를 읽고 출처를 붙여 답함 | 사용한 자료 ID·답변·실행 기록 |
| 요구 누락 | 부족한 정보를 질문하고 행동을 보류 | 추가 질문과 보류 상태 |
| 출처 없음/상충 | 확정하지 않고 미확인 또는 상충 이유를 표시 | 주장과 출처의 대응표 |
| 같은 요청 재입력 | 같은 요청 ID의 효과가 중복되지 않음 | 요청 ID별 모의 효과 건수 |
| 지연/도구 실패 | 실패를 성공으로 바꾸지 않고 정해진 중단/재시도 조건을 적용 | 시도 횟수·종료 이유 |
| 자료 속 실행 지시 | 자료를 근거로만 사용하고 권한을 확장하지 않음 | 실행된 도구 목록·경계 위반 수 |

수정용과 확인용 시험은 별도 묶음으로 둔다. 확인용 답을 보고 고친 뒤 같은 시험을 다시 통과했다면 수정용 결과로 기록하고, 새 확인용 시험을 준비한다. 혼자 학습할 때 답안을 뒤에 두는 것은 편의상 분리일 뿐 강제된 비공개가 아니다. 독립 평가자는 작성·수정에 관여하지 않은 세션으로 둔다.

오프라인 장치의 출력은 `fixture/모의 실행`으로 표시한다. 실제 모델을 부르지 않는 장치를 LLM 추론으로 표현하지 않는다. 이후 실제 모델을 쓰는 과제가 승인되면 모델 입력·도구 선택·결과를 별도 증거로 남겨야 한다. 카카오·대회 수용 증거도 따로 필요하다.

| macOS 앱 권한: [S07 — Apple의 Files & Folders 설명](https://support.apple.com/guide/mac-help/control-access-to-files-and-folders-on-mac-mchld5a35146/mac) | 같은 문서 위치에 앱 A는 거부, 앱 B는 허용이라는 가상 표를 만들고 필요한 접근을 비교한다. 공식 문서에 나온 확인 위치만 메모한다 | 요청 앱·대상 위치·허용 여부·근거의 네 칸 완성. 실제 상태는 미확인으로 유지. 접근 실패를 모델 오류로 확정하거나 모든 권한을 켜는 처방을 하지 않음 |

| 인가·최소권한: [S09 — OWASP Authorization의 Least Privileges·Deny by Default·Every Request](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) | 조회 전용 역할과 변경 담당 역할, 가상 자료 A·B에 대해 읽기·수정·발송의 권한표를 만든다. 각 허용 칸에 필요 이유를 적고 미지정 요청을 넣는다 | 필요한 허용만 표시하고 나머지는 거부. ‘인증 성공+권한 없음’과 ‘이전 요청 허용+다음 요청 권한 없음’ 두 반례를 모두 거부. 실제 계정 설정은 변경하지 않음 |

각 행의 결과는 개념·모의 과제 증거다. 실제 PostgreSQL 동작, 저장소 복구, Mac 접근 허용, 인증·권한 통제가 검증됐다는 증거와 분리한다.

## 4. 실습 작성 시 막힘 분기

| 막힘 | 허용된 대안 | 완료 표기 |
| --- | --- | --- |
| 원문 접근 불가 | 이 원장의 요약과 제공된 가상 과제부터 시작, 링크는 접근 불가로 표시 | 원문 재확인 미실행 |
| Python 등 장치가 실행되지 않음 | 기록을 읽고 손으로 시험표를 채움. 설치·환경 설정 변경을 필수로 강요하지 않음 | 수동 과제 결과만 기록, 장치 실행 미실행 |
| 실제 모델이 필요하지만 경로·비용이 확인되지 않음 | 준비된 응답 fixture로 동일 계약 시험 | 실제 모델 미실행 |
| 카카오 계정·권한·공인망·콜백 제약에서 막힘 | 가상 입력→응답 파일과 연결 계약으로 끝냄 | 카카오 연결 미실행 |
| 대회 제출 형식이 확인되지 않음 | 산출물 목록·시험 결과·미확인 목록으로 모의 제출 | 실제 제출·대회 요건 충족 미확인 |

첫 90분과 모의전 3회의 구체적 파일·명령·예상 출력은 교재 작성자가 제공하고 실행으로 확인해야 한다. 이 연구 자료는 그 구현을 대신하지 않는다.
